Why this is a white-hat view

For the first chart, we wanted to compare girls’ and boys’ primary school enrollment without hiding the differences between economies. We used the World Bank gender dataset linked in the assignment and chose the adjusted net enrollment indicators for 2017. We kept an economy only if it had a region listed in the country metadata and a recorded rate for both sexes. This removed regional and income-group totals as well as incomplete pairs. That left 80 economies. The chart does not include every economy in the world.

Each row has two dots on the same 0–100% scale. The line between them makes the gap easier to see. We calculate that gap by subtracting the male rate from the female rate, so a negative number means female enrollment is lower. The unit is percentage points, not percent change. Sorting by the gap puts the largest female disadvantages at one end and male disadvantages at the other. The region filter and search box let readers narrow the view. The chart, table, count, and summary numbers all update together, and the reset button restores the full sample.

We included both the average gap and the largest gap because an average can hide large differences. Each economy has the same weight in the average, regardless of population size. It is not a global enrollment estimate. Exact values are available in the table and on each chart row, so readers do not have to rely on color alone. Finally, enrollment is only one part of access to education. It does not tell us about attendance, learning, or why a gap exists. Missing data, reporting differences, and the source’s binary sex categories also limit what we can conclude. These are historical observations, not current enrollment figures.

Why the second chart is misleading

For the second chart, we used the same data but chose a subset that makes the results look more positive. We first kept economies where female enrollment was at least as high as male enrollment. We then sorted those economies by female enrollment and selected the top eight. This means the selection depends on the result we want to show. It is not a random sample or a group chosen for an independent reason, such as region.

The headline claims that primary education has reached gender equality, even though the chart only shows eight selected economies. Calling them “leading education markets” makes the group sound more meaningful than it is. The large 100% number is technically correct for this subset: all eight have female enrollment at or above male enrollment. But that does not mean all children are enrolled or that all economies have equal rates. A higher female rate can also mean a disadvantage for boys, rather than equality. The headline and large number encourage readers to overlook those distinctions.

We kept the plotted values and the 0–100% scale accurate. The misleading part is the choice of data and the claim attached to it, not invented numbers or a distorted axis. The reveal button makes this easier to check. It brings back all 80 eligible economies and explains how the eight were chosen. Readers can then see the gaps running in both directions and the 72 economies that were left out. Even the full sample cannot prove worldwide equality because some economies have missing data and enrollment is only one measure. Our goal was to show how a chart can use correct numbers but still give readers the wrong overall impression.

ABOUT THIS PROJECT

Where the data came from

Data and calculations

Source: World Bank gender indicators repository. Retrieved November 12, 2026. We use 2017 even though this repository contains later years.

Original gender.csv · Country metadata · Extracted observations

Both rates must be present; a nonempty metadata region identifies economies rather than aggregates. No imputation, population weighting, or rounding occurs before analysis. Display values are rounded to two decimals. The extraction script is included in the code package.

Indicator definitions: female (SE.PRM.TENR.FE) and male (SE.PRM.TENR.MA). World Bank indicators draw on UNESCO Institute for Statistics education data. This repository is a secondary copy and may differ from later revisions.

Our work

We worked on this project as a pair, Parth and Pratyaksh. It took us four hours, with each of us contributing 50% of the work.

We started by checking the dataset and finding economies with both enrollment rates available for 2017. We then built the two charts, added region and search filters, and added a button to reveal the data left out of the second chart. We checked the displayed values and tested the controls.

Implementation

We used HTML, CSS, JavaScript, and SVG without a charting library or visualization template. Both charts are drawn from the data, so the filters update the actual values rather than showing a different screenshot.
