Why this is a white-hat view

For the white-hat visualization, we looked at differences between girls’ and boys’ primary education enrollment in different economies rather than using an overall average to represent equality. We used the World Bank dataset linked to assignments (gender-indicator data for adjusted net enrollment of 2017 of primary-school-aged boys and girls). We only included economies that had a region listed in the supplemental country metadata and that had both boys’ and girls’ data (nonmissing). We did not include global, regional, or income group totals since we did not want to be counting those populations individually along with individual economies.

We have data for 80 economies. This is not a full census of all economies worldwide.

We have two dots on the same 0-100% scale that both represent each economy. By drawing a line between the two dots, we illustrate the difference within each economy (there is no uncertainty indicated by the line). The gap label indicates the difference between girls’ and boys’ enrollment as a percentage point difference (not a percent change). By sorting by this difference, we also illustrate both groups’ disadvantages.

Using a text search or selecting a region are both explicitly defined filters that can be easily reverted. Changing either of these filters changes the chart, table, summary statistics, and the count all at once. The average gap is an unweighted average of the difference in each economy (rather than an overall population-weighted gap based on overall enrollment). We also included the greatest absolute gap to ensure that averaging does not obscure extreme inequalities.

Both discussed data categories are distinguished by color. Additionally, we include a keyboard-navigable table and numerical labels as non-color-based alternatives to help illustrate the data. It is important to note that this data is related to enrollment, not attendance, not learning outcomes, not safety, and not any other aspect of gender equality. Using just two categories for sex is based on the original data rather than reflecting all possible gender identities. Comparisons are limited due to varying data reporting across economies and some data points being missing. As this dataset is based on a snapshot in time, this visualization does not indicate present data or attempt to explain why this difference exists.

Why the second chart is misleading

Our black-hat visualization claims something general about gender equality based on a carefully biased view of the same 2017 data.

First, we identified countries in which women were enrolled at 8 or above men. We ordered them based on women’s enrollment and kept the top eight. Neither this data set nor the overall claim of global progress or comparison between regions is unbiased or representative. Despite not being explained in the note (which merely acknowledges bias), calling it “leading education markets” implies that some external factor has legitimately ranked them as such.

Based on these eight countries, the title and subtitle claim something general about elementary education overall. While the prominent “100%” is mathematically accurate when limited to this data set and based on testing women being enrolled at or above men, it does not indicate that all students are enrolled, that all countries have achieved equality, or that overall gender equality has ultimately been reached. To note, being above (or below) a value can still be considered a disparity, rather than equality itself. Overall, due to the impressive nature of this data point and the general presentation of the graph, people may be led to interpret this data positively until they read the clarifications.

Both plotted points have the correct value on a shared 0-100% scale, meaning that while this data has been biased, it is not as blatantly so as fabricated data or a broken scale. Overall, the bias in this graph lies in how the data was selected and presented rather than mathematically fabricated. By clicking the audit button, users can replace the data with all 80 (available) countries and see precisely how the data was selected, how many were excluded, and what the overall range is. Seeing this data directly reveals why the positive interpretation is not legitimately justified.

Using the entire data set alone still fails to demonstrate overall gender equality due to the exclusion of data points with no value and because only enrollment is tracked. Overall, this example demonstrates that even accurate data can be used to present a false interpretation due to the power of using an available denominator and creating a bold overall statement. Overall, comparing these two graphs highlights that effective visualization is not just about being mathematically and graphically accurate, but also about appropriately limiting and clearly showing how the data was selected.

ABOUT THIS PROJECT

Where the data came from

Data and calculations

Source: World Bank gender indicators repository. Retrieved November 12, 2026. We use 2017 even though this repository contains later years.

Original gender.csv · Country metadata · Extracted observations

Both rates must be present; a nonempty metadata region identifies economies rather than aggregates. No imputation, population weighting, or rounding occurs before analysis. Display values are rounded to two decimals. The extraction script is included in the code package.

Indicator definitions: female (SE.PRM.TENR.FE) and male (SE.PRM.TENR.MA). World Bank indicators draw on UNESCO Institute for Statistics education data. This repository is a secondary copy and may differ from later revisions.

Our work

We worked on this project as a pair, Parth and Pratyaksh. It took us four hours, with each of us contributing 50% of the work. We split both the code-generation work and the reflection work equally (50/50).

We started by checking the dataset and finding economies with both enrollment rates available for 2017. We then built the two charts, added region and search filters, and added a button to reveal the data left out of the second chart. We checked the displayed values and tested the controls.

AI usage

AI was used to help with code generation and structure the reflection.

Implementation

We used HTML, CSS, JavaScript, and SVG without a charting library or visualization template. Both charts are drawn from the data, so the filters update the actual values rather than showing a different screenshot.
